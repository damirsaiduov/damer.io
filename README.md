# damer.io — updated one-file portfolio

This is the updated personal website for Damir Saiduov. The Sisyphus sketch, CSS, and clock script are embedded **directly in `index.html`** — no external assets or build tools are required.

## Replace the current GitHub Pages site

1. Download `index.html` from this package.
2. Open https://github.com/damirsaiduov/damer.io and upload the new `index.html` into the **root** of the repository, replacing the existing file. Commit the change.
3. Wait for GitHub Pages to deploy, then open https://damirsaiduov.github.io/damer.io/ and hard refresh (Ctrl+Shift+R).

Do **not** upload the ZIP itself as your site; extract it first. For your custom domain `damer.io`, configure GitHub Pages custom domain and your domain provider's DNS separately. This package intentionally does not contain a `CNAME` file so it does not override your existing domain settings.
